# Guía rápida para el encargado del menú

### Para marcar un producto como agotado
En Pages CMS abre la categoría correspondiente → producto → **Disponible = No** → guardar.

### Para reponerlo
**Disponible = Sí** → guardar.

### Para cambiar un precio
Abre el producto → cambia **Precio** → guardar.

### Para cambiar horarios
Abre **Datos generales** → **Horarios** → modifica el día → guardar.

### Para esconder una categoría completa
**Datos generales** → **Categorías** → `visible = No`.

### Para mostrar los agotados
En **Datos generales**, `Mostrar productos agotados al público = Sí`.

### Para ocultar los agotados
Pon esa opción en `No`.
